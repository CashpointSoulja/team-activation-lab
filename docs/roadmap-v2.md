# V2 roadmap (nothing here is promised in V1)

1. **Validate the metric**: historic cohort analysis of 1/2/3-learner thresholds and 7/14-day windows against 90-day retention and paid conversion.
2. **Shared experiment registry**: server-side, versioned contracts with an audit trail and owner sign-off.
3. **Analytics contract**: map events to the product analytics tool and CRM; shadow mode first.
4. **Approved CS handoff**: stall-step alerts to the account owner, with consent and opt-out.
5. **Enterprise API read-only check** (S4b), only with customer permission, to reconcile invites and completions.
6. **Power planning**: sample-size calculator in the contract step; sequential monitoring rules.
7. **Leadership proof summary**: shareable one-pager after first value (Opportunity D1).
